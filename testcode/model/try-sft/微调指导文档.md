## 微调原理简介

### 什么是微调（Fine-tuning）？

微调是在预训练模型的基础上，使用特定领域的数据对模型进行进一步训练的过程。

**核心思想：**
- **预训练阶段**：模型在大规模通用文本上学习语言的基本规律（语法、语义、常识等）
- **微调阶段**：在预训练模型的基础上，使用特定任务的数据进行训练，让模型适应特定场景

**类比理解：**
- 预训练 = 学习通用知识（像大学生学习基础知识）
- 微调 = 学习专业技能（像毕业后学习特定岗位技能）

### 微调的优势

1. **数据效率高**：不需要从零开始训练，只需要少量领域数据
2. **训练速度快**：在已有知识基础上学习，收敛更快
3. **效果好**：保留通用能力的同时，增强特定任务能力
4. **成本低**：相比全量训练，计算资源需求大幅降低

### 微调方法对比

| 方法 | 参数量 | 显存需求 | 训练速度 | 适用场景 |
|------|--------|----------|----------|----------|
| **全量微调** | 100% | 极高（>40GB） | 慢 | 资源充足，追求极致性能 |
| **LoRA** | 0.1-1% | 中等（16-24GB） | 快 | 资源有限，平衡性能与成本 |
| **QLoRA** | 0.1-1% | 低（8-16GB） | 中等 | 显存受限，需要量化 |

## LoRA 原理详解

### LoRA 是什么？

**LoRA (Low-Rank Adaptation)** 是一种参数高效的微调方法，由微软在2021年提出。

### 核心思想

传统全量微调需要更新所有参数（Qwen2.5-7B 有约70亿参数），而 LoRA 只训练少量低秩矩阵。

**数学原理：**

原始权重更新：
```
W' = W + ΔW
```

LoRA 的权重更新：
```
W' = W + BA
```

其中：
- `W`：原始预训练权重（冻结，不更新）
- `B`：低秩矩阵 B（可训练，维度：d × r）
- `A`：低秩矩阵 A（可训练，维度：r × d）
- `r`：rank（秩），通常很小（8-64）

**参数量对比：**
- 全量微调：70亿参数需要更新
- LoRA（r=16）：假设应用到 attention 的 q、k、v、o 四个投影层
  - 每个层：`r × d + r × d = 2 × r × d`
  - 4个层：`4 × 2 × 16 × 4096 ≈ 0.5M` 参数
  - 仅需更新约 **0.007%** 的参数！

### LoRA 的优势

1. **显存占用低**：只存储和更新少量参数
2. **训练速度快**：参数少，梯度计算快
3. **可组合性**：可以训练多个 LoRA 适配器，按需切换
4. **效果接近全量微调**：在大多数任务上性能差距 < 5%

### LoRA 关键超参数

- **r (rank)**：低秩矩阵的秩
  - 越小：参数越少，训练越快，但表达能力可能不足
  - 越大：参数越多，表达能力更强，但训练更慢
  - **推荐值**：16-64

- **alpha**：LoRA 缩放因子
  - 控制 LoRA 权重的影响强度
  - 通常设置为 `alpha = 2 × r` 或 `alpha = r`
  - **推荐值**：32（当 r=16 时）

- **target_modules**：应用 LoRA 的模块
  - 通常选择 attention 层的投影矩阵（q_proj, k_proj, v_proj, o_proj）
  - 对于 Qwen，还可以包括 MLP 层（gate_proj, up_proj, down_proj）

### QLoRA：LoRA + 量化

**QLoRA** 在 LoRA 基础上加入 4-bit 量化：
- 模型权重量化为 4-bit（显存减少 75%）
- 训练时反量化为 bfloat16 进行计算
- 只更新 LoRA 参数

**适用场景**：显存 < 16GB 的 GPU

## Hugging Face Token 设置

### 是否需要 Token？

**答案：取决于模型访问权限**

1. **公开模型**（如 Qwen2.5-7B-Instruct）：
   - 通常不需要 token
   - 可以直接下载

2. **Gated 模型**（需要申请访问）：
   - 需要 token
   - 需要先申请访问权限

3. **私有模型/数据集**：
   - 必须使用 token

### 如何创建 Token？

**预计时间：2-3 分钟**

1. **访问 Hugging Face 网站**
   - 打开 https://huggingface.co/
   - 注册/登录账号

2. **创建 Access Token**
   - 点击右上角头像 → **Settings**
   - 左侧菜单选择 **Access Tokens**
   - 点击 **New token**
   - 设置名称（如：`qwen-finetune`）
   - 选择权限：**Read**（下载模型/数据集）或 **Write**（上传模型）
   - 点击 **Generate token**
   - **重要**：复制 token（只显示一次！）

3. **使用 Token 的方式**

**方式 1：命令行登录（推荐）**
```bash
huggingface-cli login
# 输入你的 token
```

**方式 2：环境变量**
```bash
export HF_TOKEN="your_token_here"
# 或在代码中：
# token = os.getenv("HF_TOKEN")
```

**方式 3：代码中直接传入**
```python
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-7B-Instruct",
    token="your_token_here"  # 直接传入
)
```

**方式 4：配置文件（~/.huggingface/token）**
```bash
echo "your_token_here" > ~/.huggingface/token
```

### 验证 Token 是否生效

```bash
# 测试下载（会缓存到本地）
python -c "from transformers import AutoTokenizer; AutoTokenizer.from_pretrained('Qwen/Qwen2.5-7B-Instruct', token='your_token')"
```

## 微调步骤

### 步骤 1：准备训练脚本

**预计时间：10 分钟**

创建 `train_qwen.py`：

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
Qwen2.5-7B-Instruct LoRA 微调脚本
"""

import os
import json
from datasets import load_dataset, Dataset
from transformers import (
    AutoTokenizer,
    AutoModelForCausalLM,
    TrainingArguments,
    Trainer,
    DataCollatorForLanguageModeling
)
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training, TaskType
from transformers import BitsAndBytesConfig
import torch

# ==================== 配置 ====================
MODEL_NAME = "Qwen/Qwen2.5-7B-Instruct"
DATASET_PATH = "data/train.json"
OUTPUT_DIR = "./output/qwen2.5-7b-lora"
HF_TOKEN = os.getenv("HF_TOKEN", None)  # 从环境变量读取

# LoRA 配置
LORA_R = 16
LORA_ALPHA = 32
LORA_DROPOUT = 0.1
TARGET_MODULES = ["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"]

# 训练配置
BATCH_SIZE = 4
GRADIENT_ACCUMULATION_STEPS = 4
LEARNING_RATE = 2e-4
NUM_EPOCHS = 3
MAX_LENGTH = 512
USE_QLORA = False  # 显存不足时设为 True

# ==================== 加载模型和 Tokenizer ====================
print("加载模型和 Tokenizer...")
tokenizer = AutoTokenizer.from_pretrained(
    MODEL_NAME,
    trust_remote_code=True,
    token=HF_TOKEN
)

# Qwen tokenizer 通常已有 pad_token，如果没有则设置
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token
    tokenizer.pad_token_id = tokenizer.eos_token_id

# 配置量化（QLoRA）
quantization_config = None
if USE_QLORA:
    print("使用 QLoRA (4-bit 量化)...")
    quantization_config = BitsAndBytesConfig(
        load_in_4bit=True,
        bnb_4bit_compute_dtype=torch.bfloat16,
        bnb_4bit_use_double_quant=True,
        bnb_4bit_quant_type="nf4"
    )

# 加载模型
model = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME,
    quantization_config=quantization_config,
    device_map="auto",
    torch_dtype=torch.bfloat16 if not USE_QLORA else None,
    trust_remote_code=True,
    token=HF_TOKEN
)

# 准备 QLoRA 训练
if USE_QLORA:
    model = prepare_model_for_kbit_training(model)

# ==================== 配置 LoRA ====================
print("配置 LoRA...")
lora_config = LoraConfig(
    r=LORA_R,
    lora_alpha=LORA_ALPHA,
    target_modules=TARGET_MODULES,
    lora_dropout=LORA_DROPOUT,
    bias="none",
    task_type=TaskType.CAUSAL_LM,
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()

# ==================== 加载和预处理数据 ====================
print("加载数据集...")
# 方式1：从 JSON 文件加载
with open(DATASET_PATH, "r", encoding="utf-8") as f:
    data = [json.loads(line) for line in f]
dataset = Dataset.from_list(data)

# 方式2：直接从 Hugging Face 加载（如果已转换）
# dataset = load_dataset("json", data_files=DATASET_PATH, split="train")

def tokenize_function(examples):
    # 使用 Qwen 的 chat template
    texts = []
    for messages in examples["messages"]:
        text = tokenizer.apply_chat_template(
            messages,
            tokenize=False,
            add_generation_prompt=False
        )
        texts.append(text)
    
    # Tokenize
    tokenized = tokenizer(
        texts,
        truncation=True,
        max_length=MAX_LENGTH,
        padding="max_length",
        return_tensors="pt"
    )
    
    # Labels 就是 input_ids（因果语言模型）
    tokenized["labels"] = tokenized["input_ids"].clone()
    return tokenized

print("预处理数据集...")
tokenized_dataset = dataset.map(
    tokenize_function,
    batched=True,
    remove_columns=dataset.column_names
)

# ==================== 配置训练参数 ====================
training_args = TrainingArguments(
    output_dir=OUTPUT_DIR,
    num_train_epochs=NUM_EPOCHS,
    per_device_train_batch_size=BATCH_SIZE,
    gradient_accumulation_steps=GRADIENT_ACCUMULATION_STEPS,
    learning_rate=LEARNING_RATE,
    fp16=not USE_QLORA,
    bf16=USE_QLORA,
    logging_steps=10,
    save_steps=500,
    save_total_limit=3,
    warmup_steps=100,
    report_to="tensorboard",
    logging_dir=f"{OUTPUT_DIR}/logs",
    remove_unused_columns=False,
)

# ==================== 创建 Trainer ====================
data_collator = DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=False,
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
    data_collator=data_collator,
)

# ==================== 开始训练 ====================
print("开始训练...")
trainer.train()

# ==================== 保存模型 ====================
print(f"保存模型到 {OUTPUT_DIR}...")
trainer.save_model()
tokenizer.save_pretrained(OUTPUT_DIR)

print("训练完成！")
```

## 常见问题

### Q1: 显存不足怎么办？

**解决方案：**
1. **使用 QLoRA**：设置 `USE_QLORA = True`
2. **减小 batch size**：`BATCH_SIZE = 1` 或 `2`
3. **增加梯度累积**：`GRADIENT_ACCUMULATION_STEPS = 8` 或 `16`
4. **减小序列长度**：`MAX_LENGTH = 256` 或 `128`
5. **减小 LoRA rank**：`LORA_R = 8` 或 `4`

### Q2: 训练 loss 不下降？

**可能原因：**
1. **学习率过大**：尝试 `LEARNING_RATE = 1e-4` 或 `5e-5`
2. **数据格式错误**：检查 chat template 是否正确
3. **标签设置错误**：确保 labels 正确对齐
4. **数据质量问题**：检查数据是否合理

### Q3: 如何加速训练？

**方法：**
1. **使用更大的 batch size**（受显存限制）
2. **使用 Flash Attention**（如果支持）
3. **使用混合精度训练**（fp16/bf16）
4. **使用多 GPU**（需要修改代码，使用 `accelerate`）

### Q5: 如何合并 LoRA 权重到基础模型？

```python
from peft import PeftModel

base_model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B-Instruct")
```
